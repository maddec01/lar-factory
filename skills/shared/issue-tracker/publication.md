# Structural publication suspended

Keep maps, decomposition, attachments, Connections and Dependencies local.
`sync-structure` reports suspension without tracker writes. Settings, exploration
and attachment cannot restore it; no replacement sharing arrangement exists.
Retain pending outbox/recovery data, uncertain identities and conflicts. Neither
new identities nor confirmed-missing recovery may bypass the suspension.

Historical committed snapshots can restore kind, map, parts and relationships
through List, unqueued. They contain no ordinary brief, decision, slice or build
progress. Preserve conflicting versions and pending changes; there is no merge
or conflict UI. Suspension creates no new snapshots.

Explicit [Issue creation](issue-creation.md), ordinary [Specs](ticket-specs.md)
and [PR delivery](publication-pr.md) retain their own Access and settings rules.

## Dependency requests

Keep need, owner, contract and relationships local. Reference an existing
owning-team ticket. Create a new team request only with user authorization;
otherwise provide request text. Only the user's `mark-met` satisfies a
Dependency, never a closed ticket.
