# Retro

Input: board-confirmed delivery PR merge and Done record. Output: suggestions
saved for the desk. Run once after that confirmation; keep **Done**.

Grouped delivery: [Reconcile group](../shared/reconcile-group.md). Record progress through commands, never answer/map prose.

Show UI screenshots with captions/absolute paths beside the PR. Follow [Review session](../review-session.md).
Route suggestions per [Retro capture](../shared/retro-capture.md), then save all
with `lar-work propose-retro <work ID> --revision N --file F`. Save `[]` if none.
End the turn: the board's **Choose follow-ups** card collects the selection and
creates chosen List records/tickets. Never ask for picks in chat or create them.
