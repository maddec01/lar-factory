# Use immutable fixture keys

For this fictional disposable smoke fixture, we choose opaque UUIDs as immutable, case-sensitive Fixture keys over friendly, renameable human-readable keys. Engraved physical labels are offline references, so changing their keys would break external references and require physical relabelling. We accept UUIDs' lower readability to preserve those references, and a later change of key would require replacing labels and updating their references.

Source: [Disposable domain-docs smoke fixture #748](https://github.com/maddec01/lar-factory/issues/748).
