# Approve a changed Spec without a new Doubt review

An approved brief needs a Doubt review of its exact text before approval, and any later Spec change invalidates that review. For work that has not started building, the user's Approve as is accepts the changed text without a new review and keeps its status, because the user has read the change and the alternative is to reshape for every edit. A changed brief that no longer matches its confirmed scope, or that other work not set aside cites as a contract producer, still has to be reshaped, so [ADR 0001](0001-refined-briefs-become-ticket-main-description.md)'s fresh Doubt for producer amendments is unchanged.
