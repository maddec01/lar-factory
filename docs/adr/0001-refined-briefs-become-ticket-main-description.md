# Refined briefs become the ticket's main description

Briefs used to stay on this machine while tickets kept their authored text.
Once shaping's gate passes, the brief's team-facing prose becomes the ticket's main description
and the earlier text stays collapsed as Original. The ticket becomes the source
of truth to avoid keeping two descriptions in step, and each repository can turn
this off in Settings.

Linked-work graph and consumption declarations stay in the local brief, where
factory readers can parse them. Publishing omits those declarations, and reading
tracker prose edits back preserves them. The ticket remains the source of truth
for the product description.

Publication and reconciliation compare the same team-facing projection, including
Azure's HTML rendering. Size stays local; nonempty Notes for the builder keeps
its heading. A compatible producer amendment requires fresh Doubt, while the
consumer's approval survives only when its own approved inputs are unchanged.
Changed consumer text requires renewed approval with the changed passage shown.
